# Tree Visualization

3Dツリー構造をインタラクティブに可視化するReactアプリケーションです。Three.jsを使用して、美しい3Dグラフィックスと直感的な操作を実現しています。

## 機能

- 3Dツリー構造の可視化
- インタラクティブなノード操作
  - ノードの選択
  - 子ノードの追加
  - ノードの削除
- カメラコントロール
  - 回転
  - ズーム
  - パン
- スタイリッシュな紫を基調としたデザイン
- レスポンシブ対応

## 技術スタック

- React
- TypeScript
- Three.js
- Framer Motion

## 開発環境のセットアップ

1. リポジトリのクローン

```bash
git clone [repository-url]
cd tree-leat
```

2. 依存関係のインストール

```bash
npm install
```

3. 開発サーバーの起動

```bash
npm start
```

## 使用方法

### ノードの操作

- **クリック**: ノードを選択
- **Aキー**: 選択したノードに子を追加
- **Dキー**: 選択したノードを削除（ルートノードは削除不可）

### カメラ操作

- **左クリック + ドラッグ**: 回転
- **右クリック + ドラッグ**: パン
- **マウスホイール**: ズーム

## ビルド

本番環境用のビルドを作成する場合：

```bash
npm run build
```

## デプロイ

このプロジェクトはNetlifyでデプロイされています。`main`ブランチへのプッシュが自動的にデプロイをトリガーします。
